## 视频统一标准

- 画布：1280 × 800（16:10），保持原始比例，不拉伸；不足区域使用深墨色留边。
- 帧率：24 fps，逐行扫描。
- 编码：H.264 High Profile、YUV 4:2:0、快速起播。
- 画面：不烧录网站标题、装饰字幕、水印或伪造标记。
- 循环：首尾尽量选择相同翼拍相位；建议 4–10 秒。
- 原始科学标注允许保留，但不同视角的标注颜色、线宽和点尺寸应一致。

## 图片与曲线统一标准

- 网站图表由 CSV/JSON 直接绘制，不把截图当作最终曲线图。
- 字体：Geist / Arial；坐标轴与图例 12 px，标题 14 px，面板编号 12 px 粗体。
- 线宽：主曲线 2.5 px，辅助线 1 px；点标记 5 px。
- 颜色：腕部 `#087f8c`，翼尖 `#e45f4c`，目标线 `#132025`，辅助信息 `#7a817d`。
- 背景：`#f3f1ea`；网格透明度不超过 12%。
- 禁止使用生成式图像填补实验、机构或结果内容；缺失素材保持明确的待补状态。

替换视频后，在网站项目目录运行 `npm run media`，即可重新生成网页版本和封面帧。
